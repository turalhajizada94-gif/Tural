# Data directory

**Nothing in `raw/` or `processed/` is committed to git.** This repository is
public; participant data stays local or on approved university storage.

| Folder | Contents | In git? |
| --- | --- | --- |
| `raw/` | Qualtrics exports exactly as downloaded | No |
| `processed/` | `analysis_sample.csv` — screened, scored, de-identified | No |

## Where things come from

`raw/` is populated either by `scripts/fetch_qualtrics.py` or by you dropping a
manual Qualtrics export into it. Never edit a raw export by hand: every cleaning
decision belongs in `config/study.yaml` so it is reproducible and documented in the
data cleaning report.

`processed/analysis_sample.csv` is regenerated by `scripts/prepare_data.py` and is
safe to delete at any time.

## Keep out of this directory entirely

Anything linking response IDs to people — email lists, panel identifiers, consent
forms, interview schedules, reimbursement records. Store those separately under
whatever arrangement your ethics approval specifies.

See [the export guide](../docs/psy4414/qualtrics-export-guide.md) for the full
walkthrough.
