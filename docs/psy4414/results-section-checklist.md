# Results section — submission checklist

Built from the marking rubric, the GDPA submission guidelines and the Results
Section FAQ. Full detail and sourcing is in
[results-section-requirements.md](results-section-requirements.md).

## Before the Results section

- [ ] Aim stated (from the Introduction)
- [ ] Hypotheses / research questions stated (from the Introduction)
- [ ] Design stated (from the Method)
- [ ] Hypothesis wording confirmed with supervisor so it maps cleanly onto the analysis run

> Not graded, but a mismatch between hypothesis, design and analysis **is** taken
> into account.

## Structure

- [ ] `Results` as an APA Level 1 heading, beginning immediately after the Method (not a new page)
- [ ] Subsection: **Data Cleaning**
- [ ] Subsection: **Assumption Testing**
- [ ] Subsection: **Preliminary Analyses (Descriptive Statistics)**
- [ ] Subsection: **Inferential Statistics**

## Data Cleaning

- [ ] Participant flow, with every drop in numbers accounted for
- [ ] Non-viable responses handled and justified (passive responders, very fast completions)
- [ ] Missing data approach documented (e.g. missing value analysis)
- [ ] Reverse scoring documented
- [ ] Any exclusions justified, not merely stated

## Assumption Testing

- [ ] Every assumption for the chosen analysis tested and reported — none omitted
- [ ] Reported in text, or in text supported by tables
- [ ] Placed before the inferential analyses
- [ ] Violations addressed: statistical **and** visual evidence considered, discussed with supervisor, resolution justified

## Preliminary Analyses (Descriptive Statistics)

- [ ] Descriptives of the **study variables** (not the sample demographics)
- [ ] Presented as an APA 7th formatted table, with key points discussed in the text
- [ ] Means reported where mediation or moderation is involved
- [ ] Correlations included **here** if they are preliminary to a hypothesised model

## Inferential Statistics

- [ ] Each hypothesis tested and reported
- [ ] Correlations reported **here** instead if the relationships are themselves the hypothesis test
- [ ] Correct correlation type for the measurement level of the variables
- [ ] **Effect sizes** reported
- [ ] **Confidence intervals** reported
- [ ] Non-significant findings reported objectively — all analyses presented regardless of significance
- [ ] Post hoc analyses included where relevant and justified
- [ ] Written up following PSY4401 conventions

## Placement traps

- [ ] Cronbach's alpha for validated scales is in the **Method**, not the Results
- [ ] Cronbach's alpha is in the Results **only** if the study develops or refines a scale
- [ ] Sample demographics are in the **Method**, unless directly relevant to hypothesis testing
- [ ] Supervisor contacted if any reliability fell below .70 — **before** running the analysis

## Writing

- [ ] No interpretation of what findings *mean* — that belongs in the Discussion
- [ ] Past tense throughout
- [ ] Australian English spelling
- [ ] Headings and subheadings used to structure the section
- [ ] APA 7th in-text citations and references
- [ ] PROCESS macro referenced if used (SPSS itself does not need a reference)

## Tables and figures

- [ ] APA 7th formatting
- [ ] Each one referenced in the text
- [ ] Placed in the body, not in an appendix
- [ ] Do not count towards the word count

## Output file

- [ ] Named `Surname-GDPA-output`
- [ ] Ordered to match the order of the Results section, and labelled
- [ ] Contains only what is relevant to the final Results section
- [ ] Final reliability analysis for scales and subscales
- [ ] Data cleaning relevant to decision-making
- [ ] Descriptive analysis of the **variables**, not the sample
- [ ] Assumption testing
- [ ] Inferential analysis for **each** hypothesised model
- [ ] **Syntax boxes** included so the marker can verify the analyses

## Qualitative projects

- [ ] Themes introduced at the start of the results
- [ ] Theme map included
- [ ] Relationships between themes explained
- [ ] Extracts integrated per the guidance attached to the assessment
- [ ] Analytic lens applied — interpretation across, between, and within participants
- [ ] Wrap-up paragraph leading into the discussion
- [ ] Output evidences theme development: coded data examples, mapping of extracts, thematic flow chart
